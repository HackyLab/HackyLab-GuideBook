Seleccioná tu Caso de Instalación

CASO A

Consola Limpia (Sin Hack y Sin App PS Vue)

Si tu PS4 está original y nunca tuviste la app PlayStation Vue instalada comercialmente, este es tu método:

  • Método 1 (Restauración de Sistema): Descargá VueSystemBackup.7z (o versión Lite). Descomprimilo en la raíz de un pendrive USB. En la PS4 ve a Ajustes ➔ Sistema ➔ Copia de seguridad y restauración ➔ Restaurar PS4. Esto instalará un usuario activado localmente junto con la app PS Vue y sus datos modificados.
  • Método 2 (Extended Storage - Vue 2.0+): Podés usar el instalador de almacenamiento extendido en USB sin necesidad de formatear ni hacer un restore completo de la consola.
CASO B

Consola Ya Hackeada (PPPwn, WebKit o BD-JB previo)

Si tu consola ya tiene GoldHEN o Homebrew activo mediante otro método:

  • No necesitas hacer un System Restore. Podés instalar el paquete PKG oficial de la app PS Vue (CUSA00960).
  • Inyectá el SaveData de AfterFree usando Apollo Save Tool, transferencia FTP o la función FakeUSB directamente a la ruta de guardados.
CASO C

¿Qué pasa si uso BD-JB (Disco Blu-ray)?

El exploit mediante disco Blu-ray grabado (BD-JB) es una alternativa física ideal para FW 7.00 hasta 13.00:

  • Si no querés usar la app Vue o preferís un arranque por disco físico, grabá la ISO de BD-JB en un disco BD-RE.
  • En FW 13.00, BD-JB se puede usar para ejecutar el payload inicial o como método secundario de respaldo si Vue falla.

Paso a Paso: Ejecución y Uso Diario

Paso 01

Configuración de Seguridad y DNS

Para evitar que la consola se actualice sola durante el proceso:

  • Ve a Ajustes ➔ Sistema ➔ Descargas automáticas y desmarcá todas las casillas de actualización.
  • En Red ➔ Configurar conexión a Internet, seleccioná Personalizado y poné en DNS Primario: 62.210.38.117 (Nomadic DNS) o 127.0.0.2 (Bloqueo local).
Paso 02

Primer Arranque con USB (Solo 1ª Vez)

Preparación e inyección inicial de GoldHEN.

  • Copiá el archivo goldhen.bin en la raíz de un pendrive USB formateado en exFAT.
  • Conectá el USB a la PS4 y abrí la aplicación PlayStation Vue.
  • Aceptá la advertencia de PSN haciendo clic en OK. El exploit se ejecutará y copiará automáticamente goldhen.bin a la memoria interna (/data/) de la consola.
  • ¡A partir de este momento, ya NO necesitás conectar el USB nunca más!
Paso 03

Auto-Jailbreak y Carga de Paquetes

Automatización de GoldHEN y uso de PKGs.

  • Podés configurar el Autoloader / Auto-close en el menú de Vue para que el exploit se cierre solo a los pocos segundos tras cargar GoldHEN.
  • Ingresá a Ajustes ➔ GoldHEN ➔ Debug Settings ➔ Package Installer para instalar tus juegos y aplicaciones en formato .pkg.

Preguntas Frecuentes y Respuestas a Errores

¿Se puede usar Vue AfterFree sin pendrive USB?

Sí. El pendrive solo hace falta la primera vez para pasar el payload goldhen.bin al almacenamiento interno de la PS4 (/data/). Luego podés desenchufarlo para siempre.

¿Qué hago si sufro Kernel Panic (Apagón de la consola)?

En versiones 12.50 - 13.00, la estabilidad ronda el 60-80%. Si la consola se apaga de golpe, desenchufala unos segundos, encendela, dejá que reconstruya la base de datos y reintentá. Si persiste, considerá usar la opción BD-JB.

¿Qué es NP-Fake-SignIn?

Es un payload opcional que evita que la PS4 te pida iniciar sesión en PSN cada vez que abrís aplicaciones que requieren cuenta en la consola.
