# ⚡ Hackyntosh - Plataforma de Guías Técnicas y Modding

Bienvenido al repositorio oficial de **Hackyntosh**, un portal web diseñado para centralizar guías paso a paso sobre liberación de consolas, instalaciones de Custom Firmware (CFW), exploits por software y herramientas de modding para PC.

## 🎨 Características Web
- **Diseño Glassmorphism Púrpura/Neón**: Interfaz moderna basada en tarjetas interactivas con efectos de desenfoque y animaciones aurora.
- **Acceso Directo**: Enlaces a packs organizados sin acortadores molestos ni publicidad invasiva.
- **Formato Didáctico**: Explicaciones estructuradas con resolución de errores comunes en cada procedimiento.

## 🎮 Consolas y Sistemas Cubiertos

### PlayStation
- **PS4**: Carga de GoldHEN vía *Vue-After-Free 2.0* (Sin Hack / Copia de seguridad) y *BD-JB* (Con Hack vía Blu-ray).
- **PS3**: Instalación de *HFW 4.91* y activación de *HEN* para consolas Fat, Slim y SuperSlim.
- **PS2**: Explotación de tarjetas de memoria mediante *FreeMcBoot*, *Fortuna/FunTuna* y cargador *OPL*.
- **PSP**: Flasheo permanente universal con *PRO-C Infinity 2.0* para todos los modelos.

### Nintendo
- **Switch**: Inyección de payloads y modo *RCM* con *Atmosphere* para consolas V1.
- **Wii**: Exploit *LetterBomb* v4.3, instalación de *dDX2 cIOS* y gestores USB.
- **Nintendo DSi**: Modificación con *Memory Pit* (Cámara) e instalación de *Unlaunch + TWiLight Menu++*.
- **Nintendo DS Lite**: Configuración de cartuchos *R4*, eliminación de bomba de tiempo (*Timebomb*) kernels Wood y YSMenu.

### Xbox & eReaders
- **Xbox 360**: Carga de avatares y contenido no firmado mediante el fallo *BadUpdate / BadAvatar*.
- **Kindle**: Liberación con *LanguageBreak* para la instalación de *KOReader*.

### Herramientas PC
- Editor Hexadecimal *HxD*, *UEFITool*, descompresores y utilidades esenciales de formateo (FAT32/GUIFormat).
